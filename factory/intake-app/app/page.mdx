# Site Factory — Intake

Answer every question below. Required fields are marked ★ — the generator
refuses to run without them. Everything else improves the clone but can be
fixed later. Submitting stores the answers in Netlify Forms **and** hands you
a ready-to-run `intake.json` for `factory/generate.mjs`.

## J. Not asked here on purpose

Handled in `FINISH_SETUP.md` after generation — never through this form:

- **Admin password** — the generator writes a `changeme-…` placeholder; the
  owner sets the real one directly in `src/lib/content-data.js`.
- **Apps Script URL + read token** — produced when the Google backend is deployed.
- **Photos, prices, testimonials, FAQ copy** — the `COPY_BRIEF.md` polish pass.
